# flyer-cmyk

**English.** Claude plugin with the `impresso-grafica` skill: it guides you from idea to a
print-ready flyer or promotional piece for any campaign. It asks the key decisions
(format, paper, special finishes, AI images), collects your material step by step, and
works with marketing, marketing-psychology and graphic-design agents. It produces vector
artwork with true CMYK/Pantone, gradients, effects and outlined text, plus a validated
PDF/X-1a and separate finish masks (spot UV, foil, embossing, white ink, die-cut).
Optional AI images via OpenAI, Google or Stability, with the API key in a `.env` file.
Built for macOS. The skill speaks Brazilian Portuguese.

**Português.** Plugin do Claude com a skill `impresso-grafica`: leva da ideia ao flyer ou
impresso promocional pronto para a gráfica, para qualquer campanha. Pergunta as decisões
(formato, papel, acabamentos especiais, imagens com IA), coleta o seu material passo a
passo e trabalha com agentes de marketing, psicologia de marketing e design. Gera a arte
vetorial com CMYK/Pantone de verdade, degradês, efeitos e texto em curvas, mais o
PDF/X-1a validado e as máscaras de acabamento separadas (verniz UV, hot stamping, relevo,
tinta branca, faca). Imagens com IA opcionais (OpenAI, Google ou Stability), com a chave
num arquivo `.env`. Feito para macOS.

Install / instalar (Claude Code):

```
/plugin marketplace add Lucas-Varga/flyer-cmyk-skill
/plugin install flyer-cmyk@flyer-cmyk-skill
```

Use: *"create an A5 flyer for our grand opening to send to the print shop"* /
*"crie um flyer A5 da nossa inauguração para mandar para a gráfica"*.

Full documentation / documentação completa: https://github.com/Lucas-Varga/flyer-cmyk-skill
